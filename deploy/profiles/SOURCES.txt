workspace-seccomp.json resolves the default profile for ARM64 and the Docker default capability set, then permits clone/unshare/setns/mount/umount/pivot_root/sethostname/setdomainname for namespace-local bubblewrap operations. keyctl remains blocked with ENOSYS so runc skips its optional session keyring during nested Docker and BuildKit startup. Other privileged syscall rules remain gated out. AppArmor retains proc/sysfs protections and permits namespace-local mounts.
