# 用户使用指南

[返回首页](../../README.zh-CN.md) · [English](../en/user-guide.md)

本指南面向平台普通用户，介绍首次登录配置、开发环境与批处理任务申请、存储与镜像管理以及常见问题的处理方法。

## 1. 首次使用准备

1. 打开团队的平台地址，使用管理员分配的账号登录。
2. 进入**账号与访问 → 密码**，修改初始密码。
3. 进入**账号与访问 → SSH 密钥**，添加你的 SSH 公钥（例如 `~/.ssh/id_ed25519.pub`）。

已启用的公钥会自动生效于你在所有服务器上的开发环境；新增或禁用公钥时，运行中的开发环境也会自动同步更新。

## 2. 开发环境与批处理任务

| 任务类型 | 适用场景 | 结束方式 |
| --- | --- | --- |
| **开发环境** | 交互式写代码、调试、运行 Notebook 或 VS Code Remote-SSH | 到达预约结束时间自动停止（也可随时提前结束或停止） |
| **批处理任务** | 长时间训练、数据预处理、批量评测 | 命令执行完毕后自动退出，日志写入 `/workspace/.platform/` |

### 申请开发环境

1. 在**概览**或**开发环境**页面点击**新建开发环境**。
2. 选择**服务器**、填写任务名称并选择**镜像**。
3. 选择 GPU/NPU 数量（纯 CPU 任务选 `0`）、CPU 核数、内存与存储大小。在 GPU 算力或显存栏点击**最大**，会自动按你的剩余配额与服务器硬件上限分配。
4. 设置开始和结束时间并提交。

任务进入**运行中**状态后，打开任务详情页即可一键复制 SSH 命令或 `VS Code / ~/.ssh/config` 配置。

### 延长或提前结束开发环境

在运行中或已排期的开发环境详情页：

- **申请延长**：在单个环境的允许延期次数内申请延后结束时间。如果你的账号采用人工审批，在管理员批准前仍按原定时间结束。
- **提前结束**：立即缩短结束时间，让算力和显存更快释放给团队其他成员。

### 提交批处理任务

1. 进入**批处理任务**页面并点击**提交批处理任务**。
2. 选择启动方式：
   - **从镜像启动**：使用已保存的干净镜像运行命令。
   - **从运行中的开发环境运行**：直接复用你在交互式环境中装好的依赖。审批通过后，平台会创建内部临时镜像，停止原开发环境以释放资源，再启动批处理任务。临时镜像在保留期结束后由平台自动回收。
3. 填写要执行的命令并提交。

## 3. 存储与文件位置

每个任务容器内都会挂载三个目录：

| 容器内路径 | 存储类型 | 持久化与共享范围 |
| --- | --- | --- |
| `/home/<用户名>` | **个人卷** | 你在同一台服务器上的所有任务共享，任务结束后长期保留；不同服务器的个人卷相互独立。 |
| `/workspace` | **工作卷** | 单个任务独占（由开发环境转成的批处理任务会继承原工作卷），任务结束后保留至详情页显示的期限。 |
| `/datasets` | **共享数据集** | 该服务器上的只读团队数据集，可在**共享数据集**页面浏览或下载文件。 |

标准开发环境内置 Rootless Docker，镜像与容器数据存放在 `/workspace/.docker`，随工作卷保留策略清理。在 NVIDIA 整卡分配下，容器内可使用 `docker run --rm --gpus all IMAGE COMMAND` 共享外层任务获分配的 GPU。

## 4. 镜像管理与数据同步

在**镜像**页面管理软件环境：

- **已保存镜像**：包含团队共享镜像和你的私有永久镜像，私有镜像计入你的镜像存储配额。
- **保存开发环境**：在运行中的开发环境上执行保存操作，创建私有永久镜像。
- **通过 Dockerfile 构建**：在支持构建的服务器上通过 Dockerfile 构建私有镜像，可选填 HTTPS Git 仓库作为构建上下文。
- **构建与保存记录**：查看构建进度、保存状态与完整构建日志。

如果集群在多台服务器上启用了同步功能，可在**数据同步**页面将镜像复制到相同 CPU 架构的其他服务器。

## 5. 开发环境之间互连

当服务器启用了**环境间 SSH** 时，运行中开发环境的**连接信息**面板会显示内网 SSH 命令以及你名下其他运行中的开发环境列表。在任意一个运行中的开发环境里执行该命令（或 `scp` / `sftp`），即可直接互连，无需额外配置密钥。

## 6. 自动化与界面偏好

- **API 与 Agent 技能**（**账号与访问 → API 与 Agent 技能**）：创建 Bearer 访问令牌、查看 `/api/v1/docs` 接口文档，或下载 `gpu-platform-skill.zip` 供 AI 编程助手调用。详见 [API 与 Agent skill](api.md)。
- **偏好设置**（**账号与访问 → 偏好设置**）：切换浅色、深色或跟随系统主题，切换简体中文或英文界面，查看当前账号配额，并可按需配置个人通知接收渠道。

## 7. 常见问题排查

- **任务一直停留在“已提交”**：你的账号需要管理员审批，请等待管理员在**审批**页面处理。
- **任务一直停留在“排队中”**：目标服务器的 GPU、CPU 或内存暂时不足，待其他任务释放资源后会自动启动。
- **SSH 无法登录或提示拒绝访问**：确认任务状态为**运行中**，检查**账号与访问 → SSH 密钥**中是否已添加并启用公钥，并核对任务详情页中的端口号。
- **工作卷空间不足或即将到期清理**：在任务详情页显示的保留截止时间前，将需要长期留存的结果移至 `/home/<用户名>` 或下载到本地。
