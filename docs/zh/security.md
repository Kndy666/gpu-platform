# 身份、执行与数据边界

认证模块验证凭据并返回提供方与唯一身份。控制中心管理账号、用户组、管理员权限、语言偏好、公钥和访问令牌。本地模块使用 Django 密码验证；外部模块通过相同契约返回已验证身份。

## 账号和连接

资源配额和管理员权限分别保存。服务层检查任务、卷、镜像、令牌和同步的归属。共享镜像开放配置的读取权限。普通用户只能同步自己的私有镜像，副本计入所有者额度；管理员同步共享镜像时，目标副本自动保持共享。

默认环境使用分配的用户身份和公钥 SSH。任务页提供连接命令和独立的主机密钥别名。登录入口模块建立分配的连接路径，任务结束后关闭。管理员通过授权公钥和带审计的控制操作访问任务。

节点通信使用有大小限制、带版本号的 JSON 指令，以及独立二进制数据流。本机通信使用 Unix socket；反向 SSH 通信使用核对过的主机公钥、节点独立私钥和已有隧道。能访问节点套接字的 SSH 账号具有机器执行权限，密钥和用户组成员按此权限管理。

| 入口 | 默认值 | 配置 |
| --- | --- | --- |
| 网页与 API | TCP 8000 | 主机 `parameters.web_port`，前置 HTTPS 代理 |
| 环境 SSH | TCP 30022–30121 | `cluster.ssh_ports` |
| 节点 RPC | 主机 Unix socket | 状态目录与套接字用户组 |
| 镜像仓库 | 节点本地 TCP 5000 | 仓库选项、TLS 证书、账号凭据 |
| K3s API | 主机回环 TCP 6443 | 运行模块主机配置 |

`DJANGO_SECRET_KEY` 保存在控制中心环境和部署密钥文件中。按实际 HTTPS 来源设置受信任来源和安全 Cookie。模块凭据保存在各自的持久目录或指定密钥文件。

## 开发环境

任务运行模块通过 cgroup 限制 CPU 与内存，LXCFS 显示对应额度。模块提供支持内部用户命名空间、SSH、rootless Docker 的 AppArmor 和 seccomp 配置。配置源与许可证位于 `modules/runtime/k3s/src/gpu_platform_runtime_k3s/host/profiles`。

个人卷和工作卷作为独立存储交接物挂载，公共目录只读挂载。任务关闭自动挂载 Kubernetes 服务账号令牌。Rootless Docker 数据保存到工作卷，并共享任务的资源限制。

NVIDIA 模块负责设备发现、标准资源数量、分配记录、MPS 进程和释放。OCI 钩子在容器启动时校验任务分配。显卡算力以单卡百分比记账，显存使用 GiB；模块提供的说明描述具体硬件上的取整与共享方式。

节点容器使用特权模式、主机进程和网络空间，操作所选基础设施。工作身份和模块凭据通过明确交接物及专用文件传递。持久租约和运行记录支持节点进程重启后的恢复。

## 镜像、构建和文件

镜像仓库按归属隔离，记录镜像元数据，并在查询、导出、删除和导入时检查所有权。导出和导入使用 OCI 归档，校验归档结构、摘要、大小和目标架构。运行时拉取和镜像交接配置对应 TLS 信任。

Rootless BuildKit 使用持久队列、明确 CPU 与内存限制和超时。构建凭据和上下文绑定提交者与构建任务。私有基础镜像使用临时仓库读取授权，桥接网络内的镜像端点使用同一组受限凭据与 CA；构建器校验每个端点的 HTTPS，并在任务结束后删除凭据。完成的结果交给仓库后再发布镜像记录。

BuildKit 主机安装钩子会安装名为 `gpu-platform-buildkit` 的 AppArmor 配置，并将其应用于构建器容器。在 AppArmor 管理用户命名空间的主机上，该配置允许构建器创建用户命名空间，同时保留主机全局限制。卸载只删除由模块创建且内容未被修改的配置。

目录浏览和同步在配置根目录下解析路径，拒绝路径穿越与不安全链接。公用目录同步在目标数据盘逐文件续传，校验 SHA-256 后再替换指定目标子目录。镜像配额包含集群副本和同步中的预留。

审计事件保存代码与参数，显示跟随查看者语言，通知跟随接收者语言。备份恢复时一起保存数据库、加密密钥、节点密钥、仓库元数据、卷内容和租约状态。
