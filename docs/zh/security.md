# 安全与数据边界

[返回首页](../../README.zh-CN.md) · [English](../en/security.md)

平台账号统一关联资源归属、配额、SSH 公钥和 API 访问令牌。认证模块负责校验身份，控制服务在每次接口调用时独立校验操作权限。

## 认证与权限控制

- **浏览器会话**：前端面板通过同源 Nginx 入口访问 `/api/v1/auth/session`，使用 HttpOnly Django Session Cookie 并在写操作上校验 `X-CSRFToken`。
- **API 令牌**：脚本与 AI Agent 通过 `Authorization: Bearer <token>` 认证。携带无效 `Authorization` 请求头时一律返回 `401`，即使浏览器存在有效 Cookie 也不会回退放行。修改密码会使旧的 API 令牌失效，同时保持当前浏览器会话在线。
- **角色与配额**：普通成员仅可管理自己的任务、私有镜像、SSH 密钥和令牌；管理员权限与算力配额相互独立。
- **SSH 公钥**：在**账号与访问 → SSH 密钥**上传一次即可自动生效于全部服务器的开发环境并同步至运行中的环境。管理员使用自己的已启用公钥以目标环境的登录用户身份连接排查。

## 网络暴露边界

| 入口 | 默认暴露范围 |
| --- | --- |
| 前端面板与 `/api/v1` | `panel` 容器 TCP `8000`（公网部署建议前置 HTTPS 反向代理） |
| 控制服务 API（`web`） | 仅 Docker Compose 内部网络 TCP `8000` |
| 开发环境 SSH | TCP `30022–30121`（由 `cluster.ssh_ports` 配置），仅在任务运行期间开放 |
| 节点指令通道 | 本机 Unix 套接字，或经校验 `known_hosts` 与独立密钥的反向 SSH |
| 镜像仓库（Zot） | 节点本地 TCP `5000`，启用 TLS 与按范围签发的凭据 |
| K3s API | 宿主机回环 TCP `6443` |

请将 `.env`、`DJANGO_SECRET_KEY`、节点 SSH 密钥及通知推送令牌保存在仅 root 可读的状态目录中。

## 工作负载与构建隔离

- K3s 运行时强制执行 CPU、内存和临时盘限制，通过 LXCFS 提供符合配额的资源视图，关闭容器内 Kubernetes ServiceAccount 令牌，并应用 AppArmor 与 seccomp 策略。
- 容器内 Rootless Docker 受外层任务资源配额限制，数据存放于 `/workspace/.docker`。
- 共享数据集以只读方式挂载到 `/datasets`。
- 加速卡模块按自身模型执行隔离（NVIDIA MPS 切分或昇腾整卡独占）并持久化分配账本以支持重启恢复。`node` 容器需要主机特权、主机网络和 PID 命名空间来管理本地基础设施。
- Rootless BuildKit 构建带 CPU/内存上限、队列、取消与超时控制，私有基础镜像使用任务级短期仓库凭据，构建结束立即清理。

## 文件安全、审计与备份

- 共享数据集浏览与同步严格限制在配置根目录内，拒绝路径穿越和不安全符号链接；数据集同步在校验和通过后提交。
- 审计日志以结构化动作代码和参数持久化，按查看者语言渲染显示。
- 备份应一并包含数据库、`.env`、节点密钥、`metrics-history/`、镜像仓库元数据、分配账本和数据卷。卸载仅移除模块托管配置并保留用户数据。
