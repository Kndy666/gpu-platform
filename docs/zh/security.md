# 权限与数据边界

[首页](../../README.zh-CN.md) · [English](../en/security.md)

平台账号关联资源归属、配额、公钥和访问令牌。认证模块验证身份，控制中心逐项检查操作权限。

## 账号与 SSH

成员管理自己的任务、私有镜像、公钥和令牌。管理员角色授予管理权限，与资源配额分别设置。共享镜像按配置开放读取，私有镜像副本仍归原所有者并计入其配额。

在面板上传一次公钥，即可用于所有节点上属于该账号的环境，更新也会同步到运行中的环境。管理员使用自己的启用公钥，以目标环境的用户身份连接。公钥变更传播后影响新的 SSH 连接。

环境运行时建立登录路径，任务结束后关闭。本机节点通信使用 Unix socket，远程使用核对过主机公钥、配置独立凭据的 SSH。访问节点套接字拥有机器执行权限。

| 入口 | 默认值 |
| --- | --- |
| 面板与 API | TCP 8000，对外部署时前置 HTTPS 反向代理 |
| 环境 SSH | TCP 30022–30121，通过 `cluster.ssh_ports` 配置 |
| 节点指令 | 主机 Unix socket |
| 镜像仓库 | 节点本地 TCP 5000，使用 TLS 与限定范围的凭据 |
| K3s API | 主机回环 TCP 6443 |

HTTPS 来源和 Cookie 设置见[部署指南](operations.md)。将 `.env`、`DJANGO_SECRET_KEY`、节点凭据和模块密钥保存在受保护的状态目录。

## 开发环境与构建

运行模块限制 CPU 与内存，提供对应额度的资源视图，以及 AppArmor 和 seccomp 配置。Rootless Docker 使用任务获分配的资源，数据保存在工作卷。公共数据只读挂载，任务关闭自动挂载服务账号令牌。

加速卡模块实施各自的分配方式：NVIDIA MPS 共享算力和显存，Ascend 独占整颗芯片。分配记录持久保存，支持恢复。节点服务使用特权模式与主机网络、进程空间管理这些基础设施。

镜像仓库检查归属，导入时验证归档、摘要、大小与架构。Rootless BuildKit 构建具有 CPU 和内存限制、排队、取消与超时。私有基础镜像通过临时的限定仓库凭据访问，内部端点同样校验 TLS，任务结束后删除构建凭据。

## 文件与恢复

目录浏览和同步限定在配置根目录内，拒绝路径穿越与不安全链接。公共数据同步校验通过后才提交选定子目录；目标副本跟随源目录，也包含删除。个人卷和工作卷保留在所属节点。

审计事件保存代码与参数，按查看者语言显示；通知跟随接收者语言。一起备份数据库、加密密钥、节点密钥、仓库元数据、数据卷和分配状态。模块卸载记录自身拥有的变更，并保留用户数据和已有资源。
